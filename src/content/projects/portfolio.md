A portfolio site doesn't need a site builder or a developer. It can be pure text.

**portfolio.md** proves it. Every note, project, and photo on this site is a Markdown file with a small metadata header. The site validates each file, styles it, and publishes it. You write text; the site does the rest.

The template runs on Astro, and it compiles to plain static HTML. The output loads fast and deploys anywhere — GitHub Pages hosts it for free out of the box.

The template ships with three content types — notes, projects, and photos. A schema for each one catches missing fields at build time.
